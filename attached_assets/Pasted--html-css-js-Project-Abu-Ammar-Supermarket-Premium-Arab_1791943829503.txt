Act as a senior UI/UX designer and frontend engineer. Build a complete, professional, modern, responsive e-commerce frontend for a large Egyptian supermarket named "سوبر ماركت أبو عمار" (Abu Ammar Supermarket).
The website must look like a real, premium supermarket brand, not a basic template or a simple student project. The primary market is Egypt, and the primary language is Arabic.1. Technology Stack
Use:
React with Vite.
TypeScript where practical.
Tailwind CSS for styling.
Lucide React for icons.
React Router for navigation.
Reusable, maintainable components.
Local mock product data for the initial frontend.
LocalStorage to persist the shopping cart and customer selections.
Clean architecture that allows connecting a backend and database later.
Do not build only a static landing page. Build the full frontend experience with working navigation, product pages, search, filters, cart, and checkout.2. Branding and Visual Identity
Brand name: سوبر ماركت أبو عمار.
Design direction:
Premium, trustworthy, modern Egyptian supermarket.
Primary colors: deep supermarket green, fresh green accents, white, and subtle warm neutral backgrounds.
Use a modern Arabic font such as Cairo or Tajawal.
Full RTL layout across every page.
Excellent spacing, typography, product photography, and consistent visual hierarchy.
Subtle animations and hover effects.
Rounded product cards, soft shadows, clean icons, and polished buttons.
Use realistic, high-quality product images. Never stretch images or use unrelated placeholder images.
Create a simple text-based logo or an elegant supermarket logo treatment.
Avoid excessive gradients, clutter, and oversized empty sections.
Design mobile-first, then optimize for tablet and desktop.
The result should feel like a professional grocery delivery platform.3. Header and Navigation

Never claim that a real order has been sent or saved to a business server when no backend is connected.10. WhatsApp Order Notifications
The business wants to receive new order notifications on its phone.
Implement a configurable WhatsApp integration:
Store the business WhatsApp number in a single configuration file.
Use an international phone number format without the plus sign or spaces in the WhatsApp URL.
When the customer confirms an order, generate a formatted Arabic order message.
Include order number, customer name, phone, delivery address, selected fulfillment method, products, quantities, unit prices, subtotal, delivery fee, and final total.
Add a button labeled "إرسال الطلب عبر واتساب".
Open the WhatsApp chat with the prefilled order message using the official wa.me link format.
Encode the message correctly for URL use.
Never hardcode an invented business phone number.
Important technical limitation: opening a WhatsApp link with a prefilled message does not automatically send the message. The customer must press Send in WhatsApp. Explain this clearly in the interface.
For automatic business-side notifications without customer interaction, prepare an integration layer for a backend connected to the WhatsApp Business Platform or an approved provider. Do not expose API tokens in frontend code.11. Product Search
