# سوبر ماركت أبو عمار

واجهة متجر عربية RTL مبنية بـ React وVite وTailwind CSS. المنتجات والأسعار والمخزون في المشروع بيانات عرض توضيحية وليست بيانات المتجر الفعلية.

## التشغيل

```bash
npm install
npm run dev
```

يعمل خادم التطوير على المنفذ `5000`، ويُبنى الإنتاج باستخدام `npm run build`.

## إعداد واتساب

انسخ `.env.example` إلى `.env` وأضف رقم واتساب المتجر الحقيقي في `VITE_STORE_WHATSAPP`، بصيغة دولية من أرقام فقط، من دون `+` أو مسافات. لا تضع بيانات اعتماد أو رموز API في متغيرات `VITE_*`.

روابط واتساب تفتح رسالة جاهزة فقط. يجب على الشخص مراجعتها والضغط على «إرسال» داخل واتساب.

## ما يعمل في وضع العرض التجريبي

- تصفح الأقسام والأنواع والبحث والترتيب.
- تفاصيل المنتجات، المفضلة، وسلة محفوظة في المتصفح.
- نموذج ملخص الطلب والتحقق من رقم الهاتف المصري.
- مساعد محلي يبحث في قائمة المنتجات التوضيحية؛ ليس نموذج ذكاء اصطناعي ولا يتصل بالمخزون الحي.
- إنشاء رسائل واتساب جاهزة للمتجر أو للعميل، مع إرسال يدوي من واتساب.

## ما يحتاج خدمة خلفية قبل الاستخدام التجاري

- مخزون وأسعار حقيقية مشتركة، وإدارة منتجات وطلبات.
- حفظ آمن لبيانات العملاء، وتنبيهات تصل للمتجر عبر الأجهزة.
- إشعارات واتساب تلقائية أو تحديث حالة تلقائي للعميل.
- نموذج ذكاء اصطناعي خارجي. لم تتم إضافة مفتاح xAI؛ المساعد الحالي بحث محلي فقط.

لا تُدخل بيانات عملاء حقيقية في نسخة العرض التجريبي.
